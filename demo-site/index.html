For teams training robot policies and world models who need to know why a rollout went wrong, not just that it did.

What you get today

ii is free and local. ii run captures a layer, trains an SAE, and scores features on the adapters that ship: fake, vjepa2, hf, and groot. ii view opens the run. ii validate checks the run folder.

Quickstart

uv sync
uv run ii try

These are the install and first-run commands from the README. ii try writes practice clips and runs the pipeline on the fake model. Pass --no-open to skip the browser.

  • ii try — New here? Start with this. Finds features in a small practice model and opens the playground.
  • ii generate-clips — Write deterministic synthetic clips for the fake adapter.
  • ii run — Capture, train, extract features, score what is missing, then serve the viewer.
  • ii rank — Rank SAE features. Does not ablate; every pick still needs a real ablation.
  • ii explain — Ablate the features active in a clip and cite only real ablation effects.
  • ii serve — Serve the read API and POST /explain. Reads stay available for contract tests; the Rust server is the one to run.
  • ii rollouts — Compare baseline and intervened task success. Resume skips episodes already written.
  • ii export — Export a run as a static site: host the folder anywhere and share the link. No server needed.
  • ii export-site — Regenerate the static demo site from a fresh fake run and the vendored measurements.
  • ii validate — Validate a run folder against the schema.
  • ii view — Start a local viewer for a run folder and open it in a browser.
