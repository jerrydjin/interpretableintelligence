What you get today

ii is free and local. ii run captures a layer, trains an SAE and scores features on the adapters that ship (fake, vjepa2, hf, groot); ii view opens the run; ii validate checks it. ii rollouts compares baseline and intervened task success with matched random-feature controls and early stopping, on the bundled fake policy. ii import brings rollout logs you already have into a run folder that validate accepts.

Proof

GR00T, a robot policy

Feature 720 tracked failures, and turning it off dropped success from 39/75 to 1/9. Turning off random features caused falls too in 5 of 20 runs. `ii` makes you run that control before calling a feature real.

Run with the repo's GR00T ablation runner (ablate_v9.py), 641 rollouts. Label: Tested: no causal effect found. Explore this result.

A vision model on robot video

Open a real run: facebook/dinov2-small on 100 DROID robot clips, with 5 features that passed every check and a playground to remove or boost them.

V-JEPA 2, a world model

On V-JEPA 2, loss-based scores couldn't tell a trained SAE from a random one, so that control is now the bar.

Quickstart

uv sync
uv run ii try

ii try writes practice clips and runs the pipeline on the fake model.

  • ii tryNew here? Start with this. Finds features in a small practice model and opens the playground.
  • ii runCapture, train, extract features, score what is missing, then serve the viewer.
  • ii viewStart a local viewer for a run folder and open it in a browser.
  • ii rolloutsCompare baseline and intervened task success on the synthetic reacher. Resume skips episodes already written.
  • ii validateValidate a run folder against the schema.

The rest of the commands are in the README.
