Results

What we measured on real robot models, and the controls that decide what counts. Every number on these pages is read from a result file in the repo. A feature is called real only when it passes the scoreboard rule. The synthetic demos are at the bottom and labelled.

  • GR00T N1.7 on LIBEROFeature 720 tracked failures, and turning it off dropped success from 39/75 to 1/9. Turning off random features caused falls too in 5 of 20 runs. `ii` makes you run that control before calling a feature real. Tested: no causal effect found
  • Method checksReconstruction-only rollouts identical to baseline in 8 of 8. SAE held-out explained variance 0.998. Failure onset re-derived from pot 0.
  • V-JEPA 2 on DROIDAn SAE on a random-weights V-JEPA 2 scored higher on the loss-based checks than the trained model (loss_recovered 0.9999 vs 0.9795). Those scores cannot tell trained from random. The random-weights SAE control is not in the tool yet.
  • Attribution vs ablationOn 40 V-JEPA 2 features, attribution ranks features the way measured ablation does (Spearman 0.987) at about 3,900x less compute across all 8192 latents. Edit size alone gets 0.90.
  • DINOv2 on DROIDfacebook/dinov2-small on 100 real robot clips: 5 features passed every offline check. Try it in the browser with nothing to install; the playground is precomputed.
