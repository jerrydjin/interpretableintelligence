Run it on your own model

ii is free and runs on your laptop. Give it a Hugging Face vision model and a folder of short videos, and you get the same playground, with a check on every feature.

  1. Install

    You need git and uv. No GPU, no account.

    git clone https://github.com/jerrydjin/interpretableintelligence.git
cd interpretableintelligence
uv sync

  2. Try the practice model

    ii try finds features in a small model with three planted on purpose, so you can check what the tool finds against the truth. About 15 seconds.

    uv run ii try

  3. Your model, your clips

    Any Hugging Face vision model works: ViT-style and video encoders, CNNs, the vision tower of CLIP, SigLIP and VLMs. No clips of your own? uv run ii get-clips --out clips/droid downloads 100 short robot clips.

    uv run ii run hf --model facebook/dinov2-small \
  --clips clips/droid --out runs/mine --no-score --steer

  4. Check what you found

    Run it again without --no-score. A feature gets a tick only when it fires across many clips, its name holds on clips held back, switching it off beats random look-alike edits, and an untrained copy of the model does not have it.

Robot policies

ii rollouts switches features off inside a policy and compares task success against matched random-feature controls and an untrained dictionary, so a drop that any edit would cause is not mistaken for a finding. How we used it on GR00T.

Commands

  • ii tryNew here? Start with this. Finds features in a small practice model and opens the playground.
  • ii runCapture, train, extract features, score what is missing, then serve the viewer.
  • ii viewStart a local viewer for a run folder and open it in a browser.
  • ii rolloutsSwitch features off inside a policy and compare task success against matched random controls.
  • ii validateValidate a run folder against the schema.

Every command is in the README.

ii is free, local and open on GitHub.
