Run it yourself

ii is free and local. Try it on a practice model in a few minutes, then point it at yours.

Quickstart

uv sync
uv run ii try

ii try writes practice clips, finds features in a small practice model and opens the playground on the strongest verified one.

On a real model

Any Hugging Face vision model works. This is how the DINOv2 run in Try it was made, on short DROID robot clips:

uv run ii get-clips --out clips/droid
uv run ii run hf --model facebook/dinov2-small --clips clips/droid --out runs/droid

What you get today

ii run captures a layer, trains an SAE and scores features on the adapters that ship (fake, vjepa2, hf, groot); ii view opens the run; ii validate checks it. ii rollouts compares baseline and intervened task success with matched random-feature controls and early stopping, on the bundled fake policy. ii import brings rollout logs you already have into a run folder that validate accepts.

Commands

  • ii tryNew here? Start with this. Finds features in a small practice model and opens the playground.
  • ii runCapture, train, extract features, score what is missing, then serve the viewer.
  • ii viewStart a local viewer for a run folder and open it in a browser.
  • ii rolloutsCompare baseline and intervened task success on the synthetic reacher. Resume skips episodes already written.
  • ii validateValidate a run folder against the schema.

The rest of the commands are in the README.
