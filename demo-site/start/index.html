Run it on your own model

Free, on your laptop. No GPU, no account.

Install

You need git and uv.

git clone https://github.com/jerrydjin/interpretableintelligence
cd interpretableintelligence
uv sync

Try the practice model

ii try runs on a small model with three features planted on purpose, so you can check what it finds against the truth. About 15 seconds.

uv run ii try

Your model

Any Hugging Face vision or video model. No clips? uv run ii get-clips --out clips/droid downloads 100 short robot clips.

uv run ii run hf --model facebook/dinov2-small \
  --clips clips/droid --out runs/mine --no-score --steer

Score it

Run it again without --no-score and every feature gets the four checks.

Commands

  • ii runCapture, train, extract features, score what is missing, then serve the viewer.
  • ii viewStart a local viewer for a run folder and open it in a browser.
  • ii rolloutsSwitch features off inside a policy and compare task success against matched random controls.
  • ii validateValidate a run folder against the schema.
