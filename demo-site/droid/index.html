A real run: facebook/dinov2-small on 100 DROID robot clips, on a 4-core CPU. 5 of 3072 features passed every check (right edge of the frame, left edge of the frame, plain white ceiling or upper wall, bottom edge of the frame, white robot arm). The playground here is precomputed; it is for exploring, not evidence. A real badge means a feature passed the offline checks on held-out clips; it says nothing about what happens in a robot rollout.

Run it yourself
uv run ii get-clips --out clips/droid
# The labels here came from a vision-language model: set FIREWORKS_API_KEY (or another key, see README).
uv run ii run hf --model facebook/dinov2-small --clips clips/droid --out runs/droid
uv run ii export runs/droid --clips clips/droid --out site/droid --max-clips 10
