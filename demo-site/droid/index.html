Look inside a robot’s eyes

dinov2-small is a vision model of the kind robots use to see. We showed it 100 real robot videos and pulled out 3,072 things it has learnt to notice. Switch one off and watch how the model’s view of the scene changes.

Try it: switch off the ceiling featureor pick any clip and feature below

  1. The model watchesIt cuts each frame into small patches and describes every patch with a list of numbers.
  2. We find featuresWe split those numbers into features, each one a thing the model notices, like a robot arm or a white ceiling. An AI names each one from where it fires.
  3. We test the namesA name is a guess until it passes four checks. 5 of 3072 features passed every check and carry a green tick.
    What are the checks?
    • It fires across many different videos, not just one.
    • Its name still fits videos that were held back while it was found.
    • Switching it off changes the model more than at least 95 of 100 random look-alike edits do.
    • It is missing from a copy of the model with random, untrained weights, so it was learnt.
  4. You playPick a feature, then remove it or turn it up. The frame glows blue where the model’s view changed. This page is precomputed for exploring, not evidence: playing never changes what counts as verified.
